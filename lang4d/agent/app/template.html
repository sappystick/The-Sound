How it works

The engine reads the verse and refuses it before you see it if it contains anything other than literal arguments and one approved tool call, or if any argument is outside the tool's limits. The sentence comes from fixed templates filled from the verse's own values, and it parses back to the identical verse. Any number, amount or name in the agent's explanation that the action doesn't contain is flagged. Your approval is a signature over the verse's hash and a one-time number. The executor checks both, so a verse changed after approval, or an approval used twice, cannot run. In this page signatures use ECDSA P-256 from the browser; the Python reference (lang4d/agent/approve.py) uses Ed25519 and also sends the verse over a GSM call.
