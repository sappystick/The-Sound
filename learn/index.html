    Using it for any language

    The ladder builder needs only a text split into short units with a dictionary form for each word. It was run unchanged on the Hebrew of Genesis. To make a course it also needs a recording or voice with word timings, and a word list with meanings. The same steps then apply: hear, see, check, and meet each word again inside new text.
